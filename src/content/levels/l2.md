在固定任务和环境中调整策略的 Harness，体现了这一层的自主权。我会把研究 agent 与被优化的模型、程序分开看：修改任务中的 kernel 可以属于策略优化；修改 agent 自己的运行环境，则是 L4 要进一步讨论的对象。

策略还包括何时继续、转向和交付。一次失败如果排除了重要假设，仍可能值得；重复无效尝试则会挤掉复验与交付预算。这也是我判断[研究效率](/rsi-notes/insights/#constraints)的一部分。
